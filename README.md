# cwvp
Community Waste-to-Value: offenes Forschungs- und Beteiligungsprojekt zu lokalen Kreisläufen. Kleine überprüfbare Aufgaben, öffentliche Quellen und transparente Annahmen.

## Aufgaben

Öffentliche Aufgaben stehen als [Issues](https://github.com/intiequals1/cwvp/issues) bereit. Alle Aufgaben des Labors sammeln das [Projektboard](https://github.com/users/intiequals1/projects/6) und die [Aufgabenübersicht](https://github.com/intiequals1/digitalpath-site/issues/1).

- [#1 Forschung: einen kleinen Waste-to-Value-Pilotumfang abgrenzen](https://github.com/intiequals1/cwvp/issues/1)
- [#2 Messkonzept: minimale Materialfluss- und Wirkungstabelle entwerfen](https://github.com/intiequals1/cwvp/issues/2)
- [#3 Recherche: Pilotregion und Stakeholderrollen mit öffentlichen Quellen vergleichen](https://github.com/intiequals1/cwvp/issues/3)

Ergebnisse kommen als Markdown oder CSV in den Ordner [`docs/`](docs/).
